# Chronos Vault — 웹 기반 시계열 데이터 뷰어

[binjr](https://binjr.eu)의 핵심 기능을 웹으로 옮긴, Obsidian 테마의 CSV 시계열 뷰어입니다.
차트 하나하나가 **위젯**이며, 워크시트(**탭**) 안에서 자유롭게 배치·크기 조절할 수 있습니다.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 정적 파일 (어느 정적 호스팅에도 배포 가능)
```

## 화면 구성 (Obsidian 레이아웃)

| 영역 | 내용 |
|---|---|
| 리본 (왼쪽 끝) | CSV 열기, 샘플 데이터, 새 워크시트, 명령 팔레트, 워크스페이스 저장/열기, 테마, 도움말 |
| 왼쪽 사이드바 — 탐색기 | 불러온 CSV → 열(시리즈) 트리, 검색, 다중 선택(Ctrl/Shift), 드래그 |
| 가운데 — 탭 | 워크시트 탭 (추가 · 닫기 · 더블클릭 이름 변경 · 드래그 순서 변경 · 복제) |
| 뷰 헤더 | 시간 범위 프리셋, 시작/끝 입력, 이동/확대/축소/전체, 줌 기록 뒤로/앞으로, 크로스헤어, 드래그 모드, 레이아웃 정렬 |
| 위젯 그리드 | 헤더를 끌어 이동, 모서리/변을 끌어 크기 조절 (gridstack, 자유 배치) |
| 오른쪽 사이드바 — 속성 | 선택 위젯의 차트 유형 · Y축 · 시리즈(색상/이름/배율/오프셋/표시) 편집, 워크시트·보기 설정 |
| 상태 표시줄 | 커서 시각, 렌더 포인트 수(원본 → 표시)와 렌더 시간, 전체 포인트 수 |

## binjr 핵심 기능 대응

- **데이터 소스 트리 → 드래그 앤 드롭**: 열을 위젯 위에 놓으면 추가, 빈 공간에 놓으면 새 위젯 생성. 파일 행을 끌면 모든 열.
- **워크시트 탭 + 여러 차트**: 탭마다 독립된 위젯 레이아웃과 타임라인. 시리즈를 끌고 탭 위에 잠시 머물면 해당 탭으로 전환.
- **연동 타임라인**: 같은 워크시트의 연동된 위젯은 줌/이동을 공유. 위젯별로 연동 해제(독립 범위) 가능.
- **동기화 크로스헤어**: 한 차트에서 커서를 움직이면 모든 연동 차트에 세로선 + 시각, 범례 테이블에 커서 위치 값 표시.
- **시간 범위 선택**: 드래그 박스 줌, 휠 줌, 더블클릭 초기화, 프리셋(마지막 N시간/일), 날짜 직접 입력, 키보드 이동/확대.
- **줌 기록**: 뒤로/앞으로 (Alt+← / Alt+→). 연속 휠/이동은 한 단계로 합쳐짐.
- **이동(팬)**: Shift+드래그, 가운데 버튼 드래그, 또는 드래그 모드를 ‘이동’으로. Shift+휠 / 가로 스크롤도 이동.
- **차트 유형**: 라인, 영역, 누적 영역, 스텝, 산점도.
- **범례 테이블**: 표시/숨기기, 보이는 구간의 최소/최대/평균, 커서 값, 행 호버 시 강조, 다른 위젯으로 끌어 이동(Alt/Ctrl = 복사), 우클릭 메뉴.
- **Y축**: 자동/수동 범위, 0 포함, 로그 스케일, SI 접두사(k, M, G…), 단위. (선택적으로 Y축 줌 허용)
- **시리즈 변환**: 배율 × / 오프셋 +, 이름 변경, 색상(색각 이상 검증된 8색 팔레트 또는 사용자 지정).
- **스냅샷**: 위젯을 PNG로 저장(제목·범례 포함). 보이는 구간을 CSV로 내보내기.
- **워크스페이스 저장/열기**: 레이아웃 + 데이터를 하나의 `.chronos.json`으로. 작업 상태는 브라우저(localStorage + IndexedDB)에 자동 저장되어 새로고침 후에도 유지.
- **다크/라이트 테마**, 명령 팔레트(Ctrl+P), 단축키, 위젯 최대화.

## 대용량 CSV (수백 MB)

- **바이트 단위 파서**: Web Worker에서 파일을 16 MB씩 바이트로 읽어 필드 위치만 찾고, 숫자와 ISO 타임스탬프를 문자열 생성 없이 바로 변환합니다. 인용부호(`"`)가 있는 파일은 PapaParse로 자동 전환됩니다.
  - 278 MB · 450만 행 × 6열 → 약 5초 (헤드리스 Chromium 기준)
- **32-bit 값 저장**: 가져오기 대화상자에서 선택. 메모리 절반, 유효숫자 약 7자리. 예상 메모리가 512 MB를 넘으면 기본값이 됩니다. 시간 열은 항상 64-bit.
- **블록 요약 인덱스**: 64행마다 최소/최대(+위치)/합계/개수를 미리 계산해, 보이는 구간 통계와 다운샘플링이 원본 전체를 훑지 않습니다.
  - 1,000만 행 기준 전체 구간 M4 약 7 ms, 통계 약 2 ms (시리즈당)
- **M4 다운샘플링**: 화면 픽셀당 처음/최소/최대/마지막 값을 남겨 스파이크를 잃지 않습니다. 위젯별 “최대 포인트”(0 = 원본).
- **렌더링**: [uPlot](https://github.com/leeoniya/uPlot) canvas. 앱 번들 약 90 KB(gzip).
- **캐시 한도**: 기본 400 MB 이하의 데이터만 브라우저(IndexedDB)에 저장합니다. 더 큰 파일은 탐색기에 디스크 아이콘이 표시되고, 새로고침 후에는 “다시 열기”로 같은 파일을 열면 차트에 자동으로 다시 연결됩니다. 한도는 속성 패널의 보기 설정에서 변경.
- **워크스페이스 저장**: 데이터 합계가 150 MB 이하면 JSON에 포함, 그보다 크면 레이아웃만 저장하고 열 때 같은 파일로 재연결합니다.
- 가져오기 중 진행률과 취소 버튼이 표시됩니다.

## CSV 가져오기

- 구분자(쉼표/세미콜론/탭/파이프/공백), 헤더 유무, 시간 열, 숫자 열을 자동 감지하고 가져오기 대화상자에서 미리보기와 함께 변경할 수 있습니다.
- 시간 형식: ISO 8601(`2026-01-01 12:00:00`, `T`, 밀리초, 타임존), `DD.MM.YYYY`, `MM/DD/YYYY`, Unix epoch(초/밀리초/µs/ns 자동).
- 타임존 정보가 없는 시각은 파일에 적힌 벽시계 시각 그대로 표시됩니다(UTC 기준 저장).
- 숫자: 소수점 쉼표(`1,5`), `true/false`, `on/off` 지원. 빈 칸은 그래프의 끊김으로 표시.
- 정렬되지 않은 파일은 시간 순으로 자동 정렬.

## 단축키

| 키 | 동작 |
|---|---|
| Ctrl+P | 명령 팔레트 |
| Ctrl+O / Ctrl+S | CSV 열기 / 워크스페이스 저장 |

| + / - | 확대 / 축소 |
| A | 전체 보기 |
| Alt+← / Alt+→ | 줌 기록 뒤로 / 앞으로 |

| Delete | 선택 위젯 삭제 |
| Esc | 선택/최대화 해제 |

## 구조

```
src/
  main.ts                 부트스트랩 (IndexedDB에서 소스 복원)
  store.ts                상태 + 이벤트 + 자동 저장 + 타임라인 기록
  actions.ts              열기/샘플/저장/불러오기 등 앱 동작
  palette.ts              다크/라이트 시리즈 팔레트
  data/csv.ts             미리보기·감지, 워커 실행, 샘플 생성
  data/csvWorker.ts       청크 파싱 → Float64/Float32Array + 인덱스
  data/time.ts            타임스탬프 파싱/포맷
  data/fastCsv.ts         바이트 단위 CSV 스캐너 (숫자/ISO 시간 직접 파싱)
  data/blocks.ts          블록 요약 인덱스
  data/downsample.ts      구간 슬라이스 + M4 다운샘플링, 구간 통계
  data/db.ts              IndexedDB, 워크스페이스 직렬화
  ui/app.ts               셸(리본·사이드바·탭·상태 표시줄), 단축키, 파일 드롭
  ui/worksheetView.ts     뷰 헤더 툴바 + gridstack 위젯 그리드
  ui/chartWidget.ts       uPlot 위젯, 시계열 정렬, 휠 줌/팬, 크로스헤어, 범례 테이블, 스냅샷
  ui/explorer.ts          데이터 소스 트리
  ui/properties.ts        속성 패널
  ui/tabs.ts, commandPalette.ts, importDialog.ts, overlays.ts
  styles/app.css          Obsidian 테마 토큰/컴포넌트
```
